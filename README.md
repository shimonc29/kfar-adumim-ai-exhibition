# מעבר לדמיון — תערוכת כיתה ט׳ כפר אדומים

אתר סטטי הכולל 22 קובצי עבודות מקוריים של התלמידים.

## הרצה
פתחו `index.html` בדפדפן, או השתמשו בשרת מקומי פשוט.

## פרסום ב-Vercel
העלו את כל תיקיית הפרויקט ל-GitHub, ואז ב-Vercel בחרו Import Repository. Framework Preset: Other; Build Command: ריק; Output Directory: `.`.

## הערות
- שמות יוצרים נגזרו משמות הקבצים; יש לבדוק ולאשר את הקרדיטים לפני פרסום.
- שתי גרסאות של ״מדור לדור״ מוצגות בנפרד עד לבחירת הגרסה המועדפת.
- חלק מהפרויקטים הם הדגמות, והפעלת ממשקי API עשויה לדרוש מפתח אישי. אין לפרסם מפתחות API בקוד.
- לפני פרסום לציבור יש לבדוק זכויות יוצרים, פרטיות, דיוק עובדתי, קישורים ותפקוד אפליקציות.
