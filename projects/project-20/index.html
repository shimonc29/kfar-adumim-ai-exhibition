רובוט אמיתי

מאפס למאסטר ברובוטיקה. למד איך לחבר את החלקים, לתכנת את המוח האלקטרוני, ולעצב את הרובוט הייחודי שלך בסביבה אינטראקטיבית.

בואו נתחיל למעבדת העיצוב

איך זה עובד?

3 שלבים פשוטים בדרך לרובוט הראשון שלך

1. מבוא והיכרות

נלמד מהו רובוט, ממה הוא מורכב (חיישנים, בקר, מנועים) ואיך המוח שלו חושב.

2. חיבור פיזי

נעבוד עם חוטי גישור ומטריצה, נחבר את החיישנים והמנועים אל לוח הבקרה (Arduino).

3. תכנות (קידוד)

נכתוב שורות קוד שנותנות פקודות לרובוט: מתי לנסוע, מתי לעצור ואיך להגיב לסביבה.

איך מחברים את החלקים?

לחץ על הרכיבים כדי לראות לאן כל חוט מתחבר

חיבור חיישן אולטרסוני (HC-SR04)

  • VCC מתחבר ל-5V בארדואינו (מתח)
  • GND מתחבר ל-GND (אדמה)
  • TRIG מתחבר לפין דיגיטלי (למשל 9)
  • ECHO מתחבר לפין דיגיטלי (למשל 10)
// דוגמת קוד קצרה:
pinMode(9, OUTPUT); // Trig
pinMode(10, INPUT); // Echo

חיבור מנוע לבקר מנועים

  • חוט אדום (מנוע) מתחבר ליציאה בבקר מנועים
  • חוט שחור (מנוע) מתחבר ליציאה בבקר
  • הערה: בקר המנועים מתחבר לארדואינו דרך פיני PWM כדי לשלוט במהירות.
// דוגמת קוד קצרה:
analogWrite(enA, 255); // מהירות
digitalWrite(in1, HIGH); // קדימה
digitalWrite(in2, LOW);

חיבור נורת LED

  • רגל ארוכה (פלוס) מתחברת לפין דיגיטלי דרך נגד (220 אום)
  • רגל קצרה (מינוס) מתחברת ל-GND
  • חובה לחבר נגד כדי לא לשרוף את הנורה!
// דוגמת קוד קצרה:
pinMode(13, OUTPUT);
digitalWrite(13, HIGH); // הדלק
delay(1000);
digitalWrite(13, LOW); // כבה
